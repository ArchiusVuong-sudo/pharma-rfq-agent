1. The model reads

Claude turns each messy supplier email into a quote record through a catalog tool call and a schema-checked output. Anything it cannot read stays empty and becomes a follow-up.

2. Code decides

Registry, GMP, registration, shelf life, lead time and price checks run in code on every quote, then a planner matches each buyer to compliant suppliers by landed cost.

3. Policy routes

One policy file decides per line: act alone, ask a person (the run pauses at a checkpoint) or stop, and lists the rules that fired.
